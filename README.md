# SMART-BUILDING-SECURITY-ACCESS-CONTROL-AND-IoT-MONITORING-SYSTEM
LPC2129 ARM7-based smart access control system using PIR, RFID, keypad, PWM door control, RTC, EEPROM and CAN. Developed in Embedded C with UART, and I²C communication for authentication, real-time event logging, secure door access and inter-node data transmission.
